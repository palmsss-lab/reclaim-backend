# Staff walk-in claims

`POST /api/items/{item}/claims` records staff-entered **walk-in** claims only: send an existing walk-in `claimant_id` and nonblank `evidence_text`. An account-linked claimant returns 403 (`Account holders must submit their own claims.`); account holders submit through `POST /api/my/items/{item}/claims`. The response is 201 with `outcome: PENDING` and null review fields. Repeating the same person/item returns 409, including after rejection. Do not send outcome, submission time, or reviewer fields. This does not verify ownership, notify a walk-in without an account, or record return. The React entry point is the item's Ownership claims panel; verification, review, and physical return remain separate. Browser requests retain the existing [authentication setup](../README.md).
